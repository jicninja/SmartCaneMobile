# SmartCaneMobile

SmartCaneMobile is a mobile application designed to help users manage their smart cane cane efficiently. This project is part of the SmartCan ecosystem.

## Features

- Real-time cane status monitoring
- Notifications for full or overflowing canes
- Historical data and analytics
- User-friendly interface

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- [React Native](https://reactnative.dev/)
- [Yarn](https://yarnpkg.com/) or [npm](https://www.npmjs.com/)

### Installation

```bash
git clone https://github.com/yourusername/SmartCaneMobile.git
cd SmartCaneMobile
yarn install
```

### Running the App

```bash
yarn start
```

Follow the instructions to run on iOS or Android.
